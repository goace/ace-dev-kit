# 现状调研规范

围绕当前阶段给出的调查目的、范围和程度开展调研，为访谈和判断提供事实依据。

- Check out the current project state first (files, docs, recent commits)
- 按待解决的问题选择相关代码、文档、配置和测试，必要时追溯变更历史，查明现有行为、约束和可复用能力。
- 区分已验证事实、用户期望和待验证假设。结论保留必要的文件位置或验证依据；材料之间不一致时明确指出，不能把描述直接当作当前实现。
- 沿用前一阶段已经查明的事实，根据新增问题深入补查；事实依据发生变化时，核实受影响的结论。
- 开始时获取足以展开当前阶段讨论的背景，访谈中遇到事实缺口再补查。事实调查与提问的调度遵循[访谈规范](interview-guidelines.md)，无需等全部调查结束才讨论不受影响的问题。

调查结论按需用于当前阶段的提问和 Issue 文档，不另设调查报告。
